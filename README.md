# Portfolio

Website portofolio sederhana menggunakan Vue 3 + Vite.

## Menjalankan proyek

```bash
cd D:\hm\Aing\CV\Portfolio
npm install
npm run dev
```

## Build produksi

```bash
npm run build
npm run preview
```

## Deploy

Proyek ini cocok dideploy ke Vercel, Netlify, atau GitHub Pages setelah build.
